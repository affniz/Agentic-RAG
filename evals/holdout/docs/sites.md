# Quillfeather Sites

All Quillfeather Logistics sites, with the shift-allowance band that sets night shift pay (see the overtime policy). An operations bulletin can change a site's band. All amounts are in USD or the local equivalent.

## Europe

- Rotterdam DC. Country: Netherlands. Type: cold storage. Allowance band: B

- Leipzig Hub. Country: Germany. Type: ambient. Allowance band: A

- Lyon Crossdock. Country: France. Type: ambient. Allowance band: B

## North America

- Columbus DC. Country: USA. Type: ambient. Allowance band: A

- Reno Cold Store. Country: USA. Type: cold storage. Allowance band: C

- Hamilton Yard. Country: Canada. Type: ambient. Allowance band: B
