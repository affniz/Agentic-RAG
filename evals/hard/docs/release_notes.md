# Halcyon Fleet Release Notes

## v3.0 (November 2025)
- Introduced Fleet API v2, with streaming telemetry.
- Introduced the Batch Jobs API for scheduling commands across many robots.

## v3.1 (February 2026)
- Added Geofencing, with up to 50 zones per site.
- Deprecated Fleet API v1. Removal is planned for v3.4.

## v3.2 (May 2026)
- Added Workflows, a visual builder for multi-step robot tasks.
- Deprecated the Batch Jobs API in favor of Workflows. Existing batch jobs keep running until the API is removed.

## v3.3 (August 2026)
- Geofencing now supports up to 200 zones per site.
- The removal of Fleet API v1 is postponed to v3.5 to give large customers more time to migrate.

## v3.4 (October 2026)
- Removed the Batch Jobs API.
- Workflows is now generally available.
